Getting started

1
Install on each computer

Download and open it on every computer you want to team up. They find each other on your Wi-Fi.

2
Turn on sharing

On your extra computers, flip the Share switch. They lend their memory to the main one.

3
Pick a model and chat

On your main computer, download a model, press Start cluster, and start chatting.

What you get

Run bigger AI than one computer can

The model gets split across all your computers' memory.

Totally private

Everything runs on your own computers. Nothing is sent to the cloud.

Live performance view

See CPU, memory and speed for every computer in real time.

Eco, Balanced and Max modes

Choose how hard each computer works so it stays usable.

Requirements

WindowsWindows 10 or 11, 64-bit. 8 GB of memory or more recommended.
MacmacOS 12 or newer, Apple chip or Intel. 8 GB of memory or more recommended.

All computers should be on the same home network. Wired Ethernet makes models load much faster.
